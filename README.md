# Коровкинг

Студенческое медиа и каталог мест Москвы для учёбы, работы и встреч с командой.
Статический сайт на HTML, CSS и обычном JavaScript — без React, TypeScript и сборщиков.

## Структура

```
korovking/
├── index.html        — главная
├── places.html       — каталог мест (поиск, фильтры, список/карта, избранное)
├── place.html        — шаблон места: place.html?id=...
├── media.html        — «Медиа»: рубрики, выбор редакции, лента
├── article.html      — шаблон статьи: article.html?id=...
├── about.html        — о проекте
├── quiz.html         — квиз подбора места
├── faq.html          — частые вопросы
├── css/
│   ├── base.css      — токены, типографика, шапка, футер, кнопки, поля, модальные окна, карточки
│   └── pages.css     — стили страниц и адаптив
├── js/
│   ├── core.js       — общие функции: избранное, время Москвы, стоимость, карточки, «Поделиться»
│   ├── layout.js     — шапка, мобильное меню, футер, формы «Предложить место/материал»
│   ├── home.js, catalog.js, place.js, media.js, article.js, quiz.js — логика страниц
├── data/
│   ├── places.js     — единые данные мест (каталог, карта, подборки, избранное, квиз)
│   └── articles.js   — статьи и рубрики
└── assets/
    ├── images/       — фотографии (+ fallback.svg на случай ошибки загрузки)
    ├── icons/        — sprite.svg с иконками
    └── brand/        — логотип, маскот, фавиконки
```

Данные лежат в `.js`-файлах (а не `.json`), поэтому не нужен `fetch` и сайт работает в любом статическом хостинге. Все пути относительные — сайт открывается из подпапки репозитория на GitHub Pages.

## Запуск через Live Server

1. Откройте папку `korovking` в VS Code.
2. Установите расширение **Live Server** (Ritwick Dey).
3. Нажмите правой кнопкой на `index.html` → **Open with Live Server**.

Иконки подключаются из спрайта `assets/icons/sprite.svg`, поэтому страницы нужно открывать через локальный сервер, а не двойным кликом по файлу (`file://`).

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него содержимое папки (так, чтобы `index.html` лежал в корне репозитория или в выбранной папке).
2. **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Замена изображений

- Сейчас фотографии вырезаны из макетов и служат **визуальными примерами**. Замените их своими файлами с теми же именами в `assets/images/` — код менять не нужно. Рекомендуемая ширина: 1200 px для обложек, 900 px для карточек, формат JPEG/WebP.
- Если нужно новое имя файла, поменяйте его в `data/places.js` (`photos`) или `data/articles.js` (`cover`).
- Если файл не загрузится, вместо него автоматически покажется `assets/images/fallback.svg`.
- Логотип: `assets/brand/logo-cow.png` (шапка, футер), `assets/brand/mascot-laptop.png` (иллюстрации), `assets/brand/logo-full.png` (горизонтальный логотип), фавиконки — `favicon.png`, `favicon.ico`, `apple-touch-icon.png`. Фон приложенных изображений удалён, пропорции сохранены.

## Данные мест (`data/places.js`)

**Все 15 мест — демонстрационные примеры** (`demo: true`): названия, цены, расписания и условия придуманы для проверки фильтров. У них нет адресов и официальных ссылок, а на сайте они помечены плашкой «Пример».

Чтобы добавить настоящее место, скопируйте объект и заполните поля:

| Поле | Что это |
|---|---|
| `id` | латиница без пробелов, станет адресом `place.html?id=...` |
| `type` | `coworking`, `library`, `anticafe`, `culture`, `cafe`, `coffee`, `bakery`, `canteen` (группы — в `placeTypes`) |
| `demo` | `false` для проверенного места |
| `address` | адрес (для демо не указывается) |
| `website` | **официальный** сайт места — появится кнопка «Перейти на сайт места» |
| `district`, `metro`, `walk`, `coords` | район, станция, минут пешком, `[широта, долгота]` |
| `price` | `{ kind: 'free' \| 'hour' \| 'check' \| 'ticket', amount: число }` |
| `discounts` | `{ student: 'текст', age: 'текст' }` — пустой объект, если скидок нет |
| `amenities` | `wifi`, `sockets`, `quiet`, `team`, `calls` — `true/false` |
| `hours` | 7 массивов (пн…вс) с интервалами `["09:00","22:00"]`; через полночь — `["12:00","02:00"]`; круглосуточно — `["00:00","24:00"]`; выходной — `[]` |
| `popularity` | число для сортировки «По популярности» |
| `photos`, `alt`, `description`, `priceNote`, `rules` | фото, описание фото, тексты |

Подборка «Топ N бесплатных мест» на главной сама считает количество бесплатных мест (не больше 10).

### Как устроена стоимость

Средний чек кафе, почасовая оплата и цена входа не смешиваются. Диапазон «от — до» сравнивает только места с выбранной единицей. Сортировка по цене группирует места: бесплатные → почасовые → средний чек → вход. Фильтр «До 1000 ₽ за визит» использует открытое правило: чек, вход или 2 часа почасовой оплаты. Квиз считает почасовые места за выбранное пользователем время.

## Статьи (`data/articles.js`)

Каждая статья — объект с `id`, `title`, `rubric` (`study`, `city`, `care`, `stories`), `date`, `cover`, `coverAlt`, `lead` и `body` — массив блоков `{ t: 'p' | 'h2', x: 'текст' }` или `{ t: 'ul' | 'ol', items: [...] }`. Время чтения считается автоматически (≈180 слов в минуту). `featured: true` — материал для блока «Выбор редакции».

## Формы

Сервера нет, поэтому формы работают в честном режиме: заявка сохраняется черновиком в `localStorage` (`korovking:drafts`) и скачивается `.txt`. Чтобы подключить отправку, укажите адрес обработчика в `FORM_ENDPOINT` в `js/layout.js` — тогда форма отправит JSON методом POST и покажет «Отправлено» только после успешного ответа сервера.

## Что зависит от внешних сервисов

- **Шрифты** Onest и Caveat — Google Fonts (без интернета используются системные шрифты).
- **Карта** — Leaflet (unpkg.com) и тайлы OpenStreetMap. Если они недоступны, показывается сообщение и кнопка возврата к списку.
- **Соцсети** не выводятся: ссылок на них нет. Добавьте их в футер в `js/layout.js`, когда появятся.
